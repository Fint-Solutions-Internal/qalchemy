# QAlchemy Expo Website

Static site for FINT QAlchemy Expo 2026.

## Structure
- `index.html` - page markup
- `css/style.css` - all styles
- `js/main.js` - speaker/volunteer data + rendering
- `photos/speakers/` - speaker headshots
- `photos/volunteers/` - volunteer headshots

## Adding photos
Drop an image named to match the slug used in `js/main.js` (e.g. `raju-kumar-matcha.jpg`, `syam.jpg`) into the matching folder. If a photo is missing, the avatar falls back to initials automatically.
